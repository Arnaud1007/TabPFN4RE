# U0 legacy Ames recovery and replay

Date: 2026-09-28. Requirement: US02. Status: **engineering checks verified; historical XGBoost score reproduction failed; U0 acceptance pending**. This is retrospective development evidence only, not a holdout, temporal US, or G-US result.

## Objective and recovered inputs

Audit the now-accessible private prototype at commit `60580b6f4350a70617c6edf45d2b95ac53ebec0b` without modifying it. `data/legacy/provenance.json` identifies four byte-for-byte copied CSV artifacts and their hashes. The saved `holdout_ids.csv` has 292 unique zero-based indices in the exact legacy seed-42 split order; the 1,168-row complement is development data. The official OpenML 42165 ARFF hash is `10db9fe72ed693212a222e39981133ec1b3ee5090d7f2caf2461190a4ad51279`. The original `ames.csv` and historical installed package versions are unavailable. Holdout exposure before this audit is unknown.

The guarded `scripts/replay_legacy_ames_dev.py` verifies all source/lock hashes and skips the 292 reserved physical ARFF data lines before parsing any price. It fits and scores only the five original development folds. The exact original `run_experiment.py` was not executed because it constructs `y_hold` in memory. The replay retains the legacy model's raw `Id` feature and negative-prediction RMSLE clipping **only** to compare this historical protocol; current model policy forbids those shortcuts.
